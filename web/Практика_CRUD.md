## Выполненная работа

- Существующий каталог загружается из `js/games.json` и отображается карточками.
- Реализован просмотр полной информации об игре в модальном окне.
- Добавлена форма создания и редактирования записи. В ней можно указать название, жанр, путь к изображению, описание и платформы.
- Добавлено удаление игры с подтверждением действия.
- Изменения каталога сохраняются в `localStorage` и восстанавливаются при следующем открытии страницы.
- Добавлены стили панели управления, карточек и формы редактирования, включая адаптацию для мобильного экрана.

## Использованные технологии

- **HTML5** — каталог, формы и нативные модальные окна `<dialog>`.
- **CSS3** — оформление панели управления и адаптивной формы.
- **JavaScript** — загрузка JSON, операции CRUD, обработка форм и сохранение данных.
- **JSON** — исходные данные каталога.
- **localStorage** — сохранение пользовательских изменений в браузере.

## Как работает CRUD

1. При первом открытии страницы список загружается из `js/games.json`.
2. При последующих открытиях используются сохранённые в браузере данные, если они есть.
3. Кнопка «Добавить игру» создаёт запись, «Изменить» открывает форму с текущими значениями, а «Удалить» убирает запись после подтверждения.
4. Нажатие «Подробнее» показывает содержимое записи в окне просмотра.
5. После создания или изменения списка данные записываются в `localStorage`, поэтому остаются после перезагрузки страницы.

Поскольку сайт не использует серверную часть, браузер не изменяет непосредственно файл `games.json`. Для загрузки исходного JSON страницу следует открыть через локальный HTTP-сервер, например Live Server.

## Итог

В каталоге игр реализованы просмотр, добавление, изменение и удаление записей. Исходный JSON служит начальным набором данных, а пользовательские изменения сохраняются в браузере.
