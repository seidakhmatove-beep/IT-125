# Отчёт по заданию № 7

## Создание сайта с использованием HTML и CSS

**Выполнил:** Сейдазматов Эльдар  
**Тема проекта:** сайт игровой платформы LOGO  
**Технологии:** HTML5, CSS3

## Цель работы

Создать многостраничный сайт на HTML и CSS, оформить его в едином стиле, добавить навигацию между страницами и адаптировать основные элементы для разных размеров экрана.

## Описание проекта

LOGO — демонстрационный сайт игровой платформы. На сайте посетитель может посмотреть каталог игр, ознакомиться с вариантами подписки и поддерживаемыми устройствами, найти ответы на частые вопросы и перейти к странице аккаунта.

## Структура сайта

Все страницы сайта находятся в папке `web`:

| Файл | Назначение |
|---|---|
| `index.html` | Главная страница с обзором платформы, подборкой игр и проектов |
| `about.html` | Информация о платформе |
| `games.html` | Каталог игр |
| `subscriptions.html` | Демонстрационные планы подписки |
| `devices.html` | Информация об устройствах и подключении |
| `news.html` | Игровые новости и обновления |
| `portfolio.html` | Страница портфолио |
| `support.html` | Частые вопросы и демонстрационная форма поддержки |
| `profile.html` | Страница аккаунта и переходы к возможностям платформы |
| `login.html` | Форма входа |

Папка `web/css` содержит таблицы стилей: `style.css` для исходного оформления сайта и `pages.css` для новых страниц. В папке `web/img` размещены изображения и графические материалы.

## Использованные средства HTML и CSS

- Семантическая структура HTML: заголовки, секции, навигация, карточки, формы и подвал сайта.
- Гиперссылки для перехода между страницами и разделами.
- CSS для цветов, типографики, сеток, отступов, карточек, кнопок и эффектов при наведении.
- Медиазапросы для перестройки сеток и навигации на узких экранах.
- Изображения и SVG-элементы из папки проекта.

На странице поддержки используется небольшой JavaScript-обработчик демонстрационной формы. Он проверяет заполнение обязательных полей и показывает сообщение; отправка данных на сервер не настроена. На страницах новостей и входа подключается Bootstrap, а на главной странице — Swiper для слайдера.

## Запуск проекта

1. Открыть папку проекта `IT-125` в Visual Studio Code.
2. Запустить `web/index.html` через расширение Live Server.
3. Использовать меню сайта для перехода между страницами.

## Результат

Создан многостраничный сайт игровой тематики с единым визуальным стилем, внутренней навигацией, каталогом игр, информационными разделами и адаптивными элементами. Страницы и ресурсы проекта сгруппированы по папкам.
