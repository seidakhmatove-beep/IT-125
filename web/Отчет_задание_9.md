## Тема работы

Создание списка игр (List) и окна подробной информации (Detail) для сайта облачного гейминга LOGO с использованием данных в формате JSON.

## Цель работы

Научиться хранить данные сайта в JSON, загружать их с помощью JavaScript, формировать список элементов на странице и показывать подробную информацию о выбранном элементе.

## Выполненная работа

- Создан файл `js/games.json` с шестью объектами игр. У каждой игры указаны идентификатор, название, жанр, путь к изображению, описание и поддерживаемые устройства.
- Страница `games.html` использует каталог игр и содержит область для списка карточек.
- В `js/games.js` JSON загружается функцией `fetch`. Карточки списка создаются JavaScript-кодом для каждого элемента данных.
- Кнопка «Подробнее» открывает модальное окно с изображением, жанром, описанием игры и платформами.
- Модальное окно закрывается кнопкой, нажатием за его пределами или клавишей Escape (стандартное поведение элемента `dialog`).
- Добавлены стили карточек каталога и адаптивного модального окна в `css/games.css`.

## Использованные технологии

- **HTML5** — разметка страницы и нативный элемент `<dialog>`.
- **CSS3** — оформление карточек и модального окна, адаптация к небольшому экрану.
- **JavaScript** — `fetch`, функции, массивы, создание DOM-элементов и обработчики событий.
- **JSON** — хранение списка игр отдельно от HTML и JavaScript.

## Как работает List и Detail

1. При загрузке `games.html` скрипт запрашивает `js/games.json`.
2. Для каждой записи создаётся карточка с названием, жанром, изображением, кратким описанием и кнопкой «Подробнее».
3. При нажатии на кнопку выбранные данные подставляются в модальное окно, которое открывается вызовом `showModal()`.
4. Если JSON не загрузился, на странице выводится сообщение о необходимости открыть проект через локальный веб-сервер.

Для корректной загрузки JSON страницу нужно открыть через Live Server или другой локальный HTTP-сервер. При прямом открытии HTML-файла браузер может блокировать `fetch`.

## Итог
