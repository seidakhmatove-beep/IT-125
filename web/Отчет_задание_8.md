## Цель работы

Добавить на сайт проверку ФИО, номера телефона и электронной почты с помощью регулярных выражений на языке JavaScript.

## Выполнение задания

Для проверок создан отдельный файл `validation.js`. Он подключён на страницах `support.html` и `login.html`. В форме поддержки пользователь вводит ФИО, телефон и почту. На странице входа проверяется почта.

В `validation.js` используются три регулярных выражения:

| Данные | Регулярное выражение | Что проверяется |
|---|---|---|
| ФИО | `/^[А-ЯЁ][а-яё]+(?:-[А-ЯЁ][а-яё]+)?\s+[А-ЯЁ][а-яё]+(?:-[А-ЯЁ][а-яё]+)?\s+[А-ЯЁ][а-яё]+(?:-[А-ЯЁ][а-яё]+)?$/` | Три слова кириллицей, каждое начинается с заглавной буквы. Допускается дефис в слове. |
| Телефон | `/^\+996\s?\(?\d{3}\)?[\s-]?\d{3}[\s-]?\d{3}$/` | Номер Кыргызстана с кодом `+996`, например `+996 555 123 456`. |
| Почта | `/^[^\s@]+@[^\s@]+\.[^\s@]{2,}$/` | Адрес с символом `@` и доменной частью после точки. |

При вводе JavaScript проверяет значение. Если оно не подходит под регулярное выражение, для поля устанавливается сообщение об ошибке через `setCustomValidity()`. При отправке формы проверяется её корректность, а для правильного заполнения показывается сообщение. Данные формы поддержки на сервер не отправляются.

## Использованные средства JavaScript

- `const` для объявления регулярных выражений;
- `querySelectorAll()` и `forEach()` для поиска полей;
- обработчик события `input` для проверки введённых данных;
- `RegExp.test()` для сравнения значения с регулярным выражением;
- `setCustomValidity()` и `reportValidity()` для показа ошибок браузера;
- обработчик `submit` для проверки формы перед отправкой.

## Как проверить работу

1. Открыть `support.html` через Live Server.
2. Ввести ФИО из двух слов или неправильный телефон, например `123`, и отправить форму. Браузер должен показать сообщение об ошибке.
3. Ввести ФИО из трёх слов, например `Иванов Иван Иванович`, номер `+996 555 123 456` и правильную почту. Форма покажет сообщение об успешном заполнении.
4. Открыть `login.html` и ввести неправильную почту, например `abc`. Форма входа должна показать ошибку.
