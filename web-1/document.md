## Тема проекта

Создание сайта доски объявлений FreeMarket с использованием HTML5, CSS3 и JavaScript.

## Цель работы

Создать простой адаптивный сайт, на котором пользователь может просматривать объявления, искать товары, добавлять объявления и сохранять понравившиеся предложения.

## Задачи проекта

- Сделать десять связанных страниц сайта.
- Оформить страницы в едином современном стиле.
- Добавить адаптивную вёрстку для телефона и компьютера.
- Использовать JavaScript для поиска, фильтров, избранного, меню и форм.
- Применить темы JavaScript, которые мы проходили на занятиях.

## Использованные технологии

- **HTML5** — структура и содержимое страниц.
- **CSS3** — оформление, Flexbox, Grid и адаптивность.
- **Vanilla JavaScript** — интерактивные действия на страницах.
- **localStorage** — сохранение избранного, объявлений и настроек профиля в браузере.

Фреймворки и backend в проекте не использовались.

## Страницы сайта

1. `index.html` — главная страница с категориями, VIP-объявлениями, свежими товарами и поиском.
2. `catalog.html` — общий каталог с поиском и фильтрами.
3. `item.html` — подробная страница товара с фотографиями, описанием и телефоном продавца.
4. `add-ad.html` — форма добавления объявления.
5. `favorites.html` — список объявлений, добавленных в избранное.
6. `profile.html` — кабинет с моими объявлениями и настройками профиля.
7. `category-auto.html` — раздел автомобилей с фильтрами по цене, городу, году и пробегу.
8. `safety.html` — советы по безопасным покупкам и продажам.
9. `faq.html` — частые вопросы с раскрывающимися ответами.
10. `contacts.html` — форма обращения в поддержку.

## Что я применил(а) из JavaScript

В `script.js` использованы темы с занятий:

- **Переменные и константы** — для хранения ключей и значений.
- **Типы данных** — строки, числа, массивы, объекты и логические значения.
- **Условия `if`** — для проверки формы и выбора поведения интерфейса.
- **Функции** — для чтения и записи данных, переключения избранного и обновления страниц.
- **Массивы и методы массивов** — `filter`, `find` и `forEach` используются для работы со списками товаров.
- **Объекты** — объявление хранится как объект с названием, категорией, ценой, описанием, городом и телефоном.
- **DOM** — JavaScript находит элементы страницы, меняет их текст и классы и создаёт карточки объявлений.
- **События** — используются `click`, `input` и `submit` для кнопок, поиска, фильтров и форм.
- **JSON и localStorage** — данные преобразуются в JSON и сохраняются в браузере.

Примеры с погодой, случайными пользователями и клавиатурными событиями из конспекта я не добавлял(а), потому что они не нужны для сайта объявлений.

## Как работают основные функции

- На главной странице поисковая форма передаёт запрос в каталог. На страницах каталога и авто список фильтруется по введённому названию.
- Фильтры каталога сравнивают цену, состояние и город. В разделе авто дополнительно проверяются год выпуска и пробег.
- Нажатие на сердечко сохраняет или удаляет товар из избранного. Сохранённые товары можно посмотреть на странице `favorites.html`.
- Форма объявления проверяет заполненные поля, создаёт объект объявления и сохраняет его в браузере. Добавленные объявления показываются в кабинете.
- Настройки профиля также сохраняются в браузере.
- На странице товара кнопка показывает номер продавца.
- В мобильной версии кнопка-гамбургер открывает меню, а на странице FAQ кнопки раскрывают ответы.
- Форма контактов показывает подтверждение, но не отправляет сообщение.

## Как открыть проект

Все файлы сайта находятся в одной папке. Чтобы посмотреть сайт, откройте `index.html` в браузере. Также можно запустить страницу через расширение Live Server в Visual Studio Code.

## Ограничения проекта

Это учебный прототип. Данные сохраняются только в браузере на текущем устройстве. Объявления не отправляются на сервер, у пользователей нет регистрации и переписки. Фотографии в форме можно выбрать, но они пока не загружаются. Форма контактов не отправляет письмо. Для работы демонстрационных фотографий требуется интернет.
